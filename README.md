## Тематика застосунку
«MandryStay» — це інтерактивний веборієнтований сервіс пошуку, порівняння цін та онлайн-бронювання готельних номерів, апартаментів і туристичних турів.

## Виконання вимог Лабораторної роботи №1
1. Вибрано предметну галузь та детально описано бізнес-логіку у файлі `description.html`.
2. Головна сторінка `index.html` містить усі обов'язкові семантичні теги:
   - Заголовки різних рівнів (`h1`–`h4`);
   - Векторні зображення `<img>` з атрибутами `src`, `alt`, `title`, `width`, `height` та підписами `<figure>/<figcaption>`;
   - Багатофункціональна форма онлайн-бронювання (`<form>`, `fieldset`, `legend`, поля `text`, `date`, `number`, `email`, `tel`, `select`, `checkbox`, `radio`, `textarea`, `button`);
   - Складна тарифна таблиця (`<table>`) з `caption`, `thead`, `tbody`, `tfoot`, `th`, `td`, `colspan` та `rowspan`;
   - Різні типи списків: маркований (`<ul>`), нумерований (`<ol>`), багаторівневий та список визначень (`<dl>/<dt>/<dd>`);
   - Наскрізні гіперпосилання та посилання на сторінку опису логіки.
