## 🚀 Як відкрити у Figma за 5 секунд:

### Варіант А (Швидкий перетягуванням — рекомендований):
1. Відкрий браузер і перейди на **[figma.com](https://www.figma.com)** (увійди у свій акаунт).
2. Відкрий будь-який файл або створи новий порожній чернетковий файл (**New design file**).
3. Просто **перетягни (Drag & Drop)** файл `MandryStay_Figma_Master_Project.svg` (або окремі `.svg` файли) зі своєї папки прямо на полотно Figma!
4. Figma миттєво імпортує його як векторні об'єкти з усіма шарами, текстами, фігурами та кольорами.

### Варіант Б (Через меню імпорту):
1. На головній сторінці Figma (Drafts) у правому верхньому куті натисни кнопку **«Import»**.
2. Обери файл `MandryStay_Figma_Master_Project.svg`.
3. Figma створить новий проект з назвою `MandryStay_Figma_Master_Project`.
